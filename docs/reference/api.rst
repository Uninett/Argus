API Endpoints

Exploring the API
=================

An OpenAPI schema is available for each version at ``/api/vVERSION/schema/``.
An UI for exploring each version is at ``/api/vVERSION/schema/swagger-ui/``.

Which versions of the API that are available on a given server is fetchable from
``/api/``.

All the above links are accessible without authenticating.
